# Goldmine Alert Workflow

**Primary Agent:** Chief
**Type:** Triggered / Configuration

---

## Goal

Configure alert thresholds and trigger notifications when goldmine opportunities are detected.

---

## Workflow Steps

### Step 1: Configuration Review

Review current alert configuration.

```yaml
config:
  opportunity_threshold: 90
  trend_spike_threshold: 200%
  notification_channels:
    - sidecar_memory
    - daily_briefing
```

### Step 2: Alert Check

Check for conditions that meet alert criteria.

```yaml
triggers:
  - opportunity_score >= threshold
  - trend_velocity >= spike_threshold
  - new_niche_detected
  - competitor_weakness_found
```

### Step 3: Alert Generation

Generate alert with full context.

```yaml
alert_content:
  - Alert type
  - Trigger reason
  - Relevant data
  - Recommended action
  - Confidence level
```

### Step 4: Notification

Store alert and update relevant agents.

```yaml
actions:
  - Save to ode-chief/memories.md
  - Include in next daily briefing
  - Update alert history
```

### Step 5: Configuration Mode

Allow user to adjust alert settings.

```yaml
configurable:
  - opportunity_threshold (50-100)
  - trend_sensitivity (low/medium/high)
  - alert_frequency (immediate/batched)
```
