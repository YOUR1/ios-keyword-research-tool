# Daily Briefing Workflow

**Primary Agent:** Chief
**Type:** Scheduled / On-demand

---

## Goal

Compile data from all ODE agents into a comprehensive daily intelligence report.

---

## Workflow Steps

### Step 1: Data Gathering

Collect reports and data from all agents for the past 24 hours.

```yaml
sources:
  scout:
    - Recent keyword discoveries
    - Trend signals
    - Market movements
  analyst:
    - Opportunity scores
    - Niche analyses
    - Sentiment patterns
  ops:
    - System status
    - Crawl statistics
    - Error reports
```

### Step 2: Keyword Summary

Summarize new and trending keywords discovered.

```yaml
keyword_summary:
  - New keywords discovered (24h)
  - Top trending keywords
  - Category distribution
  - Confidence levels
```

### Step 3: Opportunity Summary

Highlight the top opportunities identified.

```yaml
opportunity_summary:
  - Top 10 opportunities by score
  - New opportunities since last briefing
  - Niche performance overview
```

### Step 4: Alert Review

List any goldmine alerts triggered in the past 24 hours.

```yaml
alerts:
  - High-value opportunities (score > 90)
  - Unusual trend spikes
  - New market entrants
```

### Step 5: System Status

Include operational health from Ops agent.

```yaml
system_status:
  - Database health
  - Cache performance
  - API rate limits
  - Recent crawl results
```

### Step 6: Recommendations

Generate actionable recommendations based on findings.

```yaml
recommendations:
  priority_levels:
    - IMMEDIATE: Goldmine opportunities
    - HIGH: Trending niches
    - MEDIUM: Emerging keywords
    - LOW: Monitor items
```

### Step 7: Format Report

Compile everything into the final briefing document.

---

## Output

```yaml
output:
  file: "daily-briefing-{date}.md"
  format: |
    ## Daily Intelligence Briefing
    **Date:** {date}
    **Classification:** STANDARD

    ---

    ### Executive Summary
    {executive_summary}

    ### Keyword Intelligence
    - New keywords: {new_keyword_count}
    - Top trend: {top_trend}
    {keyword_details}

    ### Opportunity Report
    - Opportunities found: {opp_count}
    - Highest score: {max_score}
    {opportunity_table}

    ### Alerts (24h)
    {alerts_list}

    ### System Status
    {ops_status}

    ### Recommended Actions
    {prioritized_recommendations}

    ---
    **End of Briefing**
    _Generated by ODE Chief_
```
