# ode-analyst Sidecar

This folder stores persistent memory for the **Analyst** agent.

## Purpose

Analyst needs to remember previous analyses, opportunity scores, and niche
assessments to track changes over time and provide comparative insights.

## Files

- `memories.md` - Opportunity scores, niche analyses, sentiment patterns, user preferences
- `instructions.md` - Goldmine formula, protocols, collaboration rules

## Runtime Access

After BMAD installation, this folder will be accessible at:
`{project-root}/_bmad/_memory/ode-analyst/`
